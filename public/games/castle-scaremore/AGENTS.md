# Repository scope

This repository is exclusively for Castle Scaremore.
Remote: https://github.com/milchinien/Castle-Scaremore.git

Keep changes within this game. Do not add sibling games, the parent workspace, video-production projects, or local review screenshots to this repository.

The repository root is the game directory itself, even when its local folder name is `ghost-castle`. Serve this directory directly; no build step is required. Preserve the Original and Moonlit design choices and existing browser save compatibility when changing the game.
