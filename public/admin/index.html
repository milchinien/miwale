Verwaltung einrichten

Es gibt noch kein Admin-Konto. Lege das erste an. Dafür brauchst du das alte Verwaltungs-Passwort (Variable BEWERTUNGEN_ADMIN_PASSWORT auf dem Server, lokal „dev“). Danach gilt es nicht mehr.

Bestätigungscode

Für dein Konto ist noch kein zweiter Faktor eingerichtet. Richte ihn jetzt ein:

  1. Öffne eine Authenticator-App, z. B. Google Authenticator, Aegis oder 1Password.
  2. Wähle „Konto hinzufügen“ → „Schlüssel eingeben“ (bzw. „Einrichtungsschlüssel“).
  3. Kontoname: , Schlüssel: der Code unten, Typ: zeitbasiert.
  4. Gib den 6-stelligen Code ein, den die App dann zeigt.
In Authenticator-App öffnen

Auf dem Handy öffnet der Link die App direkt. Bewahre den Schlüssel nicht unverschlüsselt auf.

Gib den 6-stelligen Code aus deiner Authenticator-App ein.
