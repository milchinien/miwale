Auf diesem Gerät läuft noch kein Agent

Der Agent ist ein kleines Programm, das nur auf diesem Rechner läuft. Er zeigt der Seite die eigenen Dev-Server und startet oder beendet sie. Einmal pro Rechner einrichten (Windows, Node.js muss installiert sein):

  1. Befehl kopieren: Kopiert ✓
  2. Win + R drücken, mit Strg + V einfügen, Enter.
  3. Fertig. Ab jetzt startet der Agent mit Windows, und Strg + Alt + D öffnet diese Seite.

Läuft der Agent schon und die Seite findet ihn trotzdem nicht? Dann fragt der Browser vermutlich, ob miwale.com auf Geräte im lokalen Netzwerk zugreifen darf — oben links neben der Adresse auf „Zulassen“ stellen.
